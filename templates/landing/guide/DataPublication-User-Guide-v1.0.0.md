---
title: DataPublication User Guide v 1.0.0
---
With this Quick Start Guide we would like to provide you with do’s and dont’s and some basic information on how to register, create and edit your dataset, choose a license and successfully publish your data in DataPublication.


As DataPublication is based on the repository software Dataverse, you are welcome to also consult the detailed [Dataverse User Guide](https://guides.dataverse.org/en/latest/user/index.html) for information on the system and its functionality.
