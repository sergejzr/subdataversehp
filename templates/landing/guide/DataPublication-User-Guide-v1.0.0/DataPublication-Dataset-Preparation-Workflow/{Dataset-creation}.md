title: Dataset Creation
---
To create a dataset, after logging in, click on "Add Data" and then "New Dataset". Here, you need to fill in all mandatory metadata fields in the metadata form. At this stage you can also upload any data files you have already prepared for your dataset in the section "Files". File upload can also be done later, see XXXXXX.

**Hint:** If you would like to add a dataset directly to an existing collection in DataPublication, please go to the DataPublication landing page, click on "Add Data" and then choose the relevant collection from the drop-down menu.

When complete, click on "Save Dataset". Once saved, a Draft Version of the dataset will be created with a DOI (Digital Object Identifier) assigned to it. The DOI will be inactive until the dataset is verified by the responsible administrators and published. 

Please note that, although assigned upon dataset creation, inactive DOIs should not be passed on further. This also involves including an inactive DOI in an article submission to a journal. If you need to provide the journal with a DOI to your dataset before it is published, please contact the DataPublication administrators. The administrators can then reserve the inactive DOI for the dataset and the DOI can afterwards be shared with the journal.

Please note, that once a DOI is reserved, the draft dataset needs to be eventually published as it is formally coupled with the DOI! 

**Hint:** An overview of your published, submitted for review and draft datasets can be found in your account information under "My Data".

**Please note:** All data in your dataset should be cleaned-up and documented in such a way that other scientists and third parties, without prior knowledge of your work or your publications, can understand and classify your data.
This is accomplished by including a text file (a so-called readme file) with the dataset in which the data is described in as much detail as possible. This documentation – preferably in English - should contain relevant information on the collection, structure and processing of the data.
