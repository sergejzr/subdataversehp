---
title: Mandatory and optional metadata
---
Upon dataset creation, the user will be prompted to provide basic, mandatory metadata information about the dataset. In order to successfully create a dataset, the mandatory metadata fields need to be filled out!

Mandatory fields are marked with red asterisks. All remaining fields are optional and should be filled out as appropriate.
The optional metadata fields can be filled out upon dataset creation, as well as edited afterwards: If you wish to add or edit the metadata of your created dataset, please go to "Edit Dataset" and click on "Metadata" on the dataset's landing page.

Upon dataset publication, the metadata fields are available to anyone under a [CC-0 license](https://creativecommons.org/publicdomain/zero/1.0).

Next to each metadata field, the user will find question mark symbols. These provide a description as to what information should be included for each field.

**Hint:** Upon dataset creation, one cannot choose a license. It is set per default to CC-0.In order to assign / change a license, please go to "Terms" and click on "Edit Terms Requirements". For more information please see section  3.5 Choosing appropriate licenses for your research data of the User Guide XXXXXXX.

If needed, you can also add more subject-specific metadata to your dataset. Currently, DataPublication has the following subject-specific metadata schemes available:

- Geospatial Metadata (not active per default),

- Social Sciences and Humanities Metadata (not active per default),

- Astronomy and Astrophysics Metadata (not active per default),

- Life Sciences Metadata (not active per default),

- Computational Workflow (active),

- Software Metadata (active).

The above listed subject-specific metadata can be also customed for sub collections in DataPublication.

For more information about the metadata schemes in DataPublication, please consult the [Dataverse User Guide](https://guides.dataverse.org/en/latest/user/appendix.html).

For more information about metadata available in Dataverse, please consult the [Dataverse User Guide](https://guides.dataverse.org/en/latest/user/index.html).
