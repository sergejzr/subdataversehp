---
title: Choosing a thumbnail image for a dataset
---
Thumbnail images can be assigned to a dataset manually or automatically. The thumbnail for a dataset appears on the search result card for that dataset and on the dataset page itself.

**Hint:** If a dataset contains one or more data files that is recognized as an image, then one of those images is automatically selected as the dataset thumbnail.

If you would like to manually select your dataset’s thumbnail, you can do so by clicking on the *Edit* button, and selecting *Thumbnails + Widgets* from the dropdown menu.

Under the Thumbnail tab you will see three possible actions:

***Select Available File*:** Click on  *Select Thumbnail* to choose an image from your dataset to use as the dataset thumbnail.

***Upload New File:*** Upload an image file from your computer to use as the dataset's thumbnail. While by default your thumbnail image is drawn from a file in your dataset, this will allow you to upload a separate image file to use as your dataset thumbnail. This uploaded image file will only be used as the dataset thumbnail; it will not be stored as a data file in your dataset.

***Remove Thumbnail:*** If you click the *Remove* button under the thumbnail image, you will remove the dataset’s current thumbnail. The dataset will then revert to displaying a basic default icon as the dataset thumbnail.

Be sure to click on *Save Changes* before leaving the page.

**Hint:** Alternatively, it is also possible to define an image file in your dataset as your thumbnail image by selecting the file, going to *Edit Files* -\> *Metadata*, and using the *Set Thumbnail* button.
