---
title: Setting an embargo for files in a dataset
---
To set up en embargo for a file or files in your dataset select the file(s) by checking the box to the left of the file name. Click on the *Edit files* button above the file section to the right, and choose *Embargo.
*

![Embargo-2](uploads/e58657672c74d1e0ea80eee4adb27ef6/Embargo-2.png){width=1000 height=515}

A pop-up window *Edit Embargo* will appear. Here you can select the embargo end-date, add a reason for why the file(s) are embargoed and remove existing embargo(es), if necessary.
Please note that once a dataset is published, changes regarding the embargo end-date or embargo reason can only be performed by the respective administrator.

![Embargo-1](uploads/4623f23fbedbb25cdbc6cdb5fd09eed5/Embargo-1.png){width=1000 height=473}

**Hint:** Setting an embargo on relevant files and publishing the dataset in DataPublication activates the DOI for the dataset and makes the metadata, and any content of un-embargoed files immediately available, but automatically denies access to any embargoed files until the specified embargoes expire. Once a dataset with embargoed files has been published, no further action is needed to cause the embargoed files to become accessible as of the specified embargo end date. Note that embargoes can be set along with using the ‘restrict’ functionality on files. The restricted status will affect their availability once the embargo expires. Setting the same embargo on all files in the dataset can be seen as providing a dataset-level embargo - making the dataset DOI and metadata available but restricting access to all files. For more information see the [Dataverse User Guide](https://guides.dataverse.org/en/latest/user/dataset-management.html).
