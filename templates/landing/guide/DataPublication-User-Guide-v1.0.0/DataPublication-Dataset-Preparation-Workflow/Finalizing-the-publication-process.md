---
title: Finalizing the publication process
---
As long as the dataset remains a draft, the attachments can be corrected, added and removed and the metadata can be edited.

**Hint:** As an author of a dataset, you have an option to choose an thumbnail image for your dataset. The dataset thumbnail, if assigned, appears on the search result card for that dataset and on the dataset page itself. See [3.10 Choosing a thumbnail image for a dataset](/DataPublication-User-Guide-v1.0.0/DataPublication-Dataset-Preparation-Workflow/Choosing-a-thumbnail-image-for-a-dataset) for more details.

When the dataset is complete, please click on the *Submit for review* button and the draft dataset will be sent to the administrators for technical and content integrity verification (for example whether any metadata entries are missing or should be included). At this stage, the dataset cannot be edited anymore by the Contributor:  the buttons "Submit for review" and "Edit dataset" are disabled.

**Please note:** Please note that all listed authors of the dataset should agree to the dataset and all its contents being published\!

If the verification process shows that the dataset is incomplete (for example missing readme file), the administrator returns the dataset to the dataset Contributor. Such a dataset can then be again edited. After revising the dataset and adding the necessary information, the dataset can be again submitted for review.   If the dataset is successfully reviewed, the administrator publishes it. The dataset contributor receives a corresponding E-mail notification. Once a dataset is published, the DOI becomes active and the dataset is available permanently. 

**Please note:** The review process can take, on average, up to 3 working days.

After publishing, it is no longer possible to make further changes to this version of the dataset. In certain cases however, for example when a new version of a method is developed or the method is corrected, it is possible to create a new version based on an existing, published dataset.
