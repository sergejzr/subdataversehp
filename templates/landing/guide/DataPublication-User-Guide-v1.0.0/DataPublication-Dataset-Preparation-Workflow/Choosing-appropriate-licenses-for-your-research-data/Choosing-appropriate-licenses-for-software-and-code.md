title: Choosing appropriate licenses for software and code
---
**Please note:** Please note that for any code that you would like to publish via DataPublication it is **required to have notices regarding the license at the start of each source file**. Each file should also have a pointer to the main license notice comprising of the full license.

For more information see for example the GNU License Webpage [FAQ](https://www.gnu.org/licenses/gpl-faq.en.html#NoticeInSourceFile) and its section on [How to Apply These Terms to Your New Programs](https://opensource.org/license/gpl-3-0/) (section to be found at the bottom of the GPL License, after the terms and conditions).

More information on software and code can be found on our page [Forschungssoftware und Code](/references/Forschungssoftware-und-Code) (currently only in German).

Currently there are 5 software & code specific licenses enabled in DataPublication:

![mit-license-2506118654](uploads/a0a699468711c4e46aa1b3425c3ce941/mit-license-2506118654.png){width=300 height=106}The **[MIT License](https://opensource.org/license/mit/)**: A short, permissive software license. Basically, you can do whatever you want as long as you include the original copyright and license.

![apache2-0](uploads/bbfb19789d3f5b9564ff91684b32ee18/apache2-0.png){width=300 height=106}The **[Apache 2.0 License](https://www.apache.org/licenses/LICENSE-2.0)**: A license that allows you much freedom with the software, including an explicit right to a patent. "State changes" means that you have to include a notice in each file you modified. 

![gpl-v3](uploads/fdfbfb90ef43164b9112fbb94df1bf52/gpl-v3.png){width=250 height=95}The **[GPLv3 License](https://opensource.org/license/gpl-3-0/)**: You may copy, distribute and modify the software as long as you track changes/dates of in source files and keep modifications under GPL. You can distribute your application using a GPL library commercially, but you must also provide the source code.

![lgpl\_license-logos-by-christian-candena-cc-by](uploads/f1e95f950c5e4afdde961aead500796a/lgpl_license-logos-by-christian-candena-cc-by.png){width=250 height=80} The **[LGPLv3 License](https://opensource.org/license/lgpl-3-0/)**: You may copy, distribute and modify the software provided that modifications are described inside the modified files and licensed for free under LGPL-3.0. Derivatives or non-separate (statically-linked) works of the software must be licensed under LGPL, but separate, parent projects don't have to be.

![bsd-license-300x106-394018037](uploads/255a8e88358a70883281e9fc62e3106f/bsd-license-300x106-394018037.png){width=300 height=106}The **[BSD License](https://opensource.org/license/bsd-3-clause/)**: The BSD 3-clause license allows you almost unlimited freedom with the software so long as you include the BSD copyright notice in it. "Use trademark" in this case means you cannot use the names of the original company or its members to endorse derived products.

###### The descriptions of the listed licenses were taken from the [Public License Selector](https://ufal.github.io/public-license-selector/).

-----

Analogous to choosing licenses for research data, kindly specify the the desired software license by selecting it from the *Dataset Terms* drop-down menu:

![software-licenses\_overview](uploads/22edce046aa01c336f96ffb3eeb0c903/software-licenses_overview.png){width=1000 height=328}

If you would like to grant a different software license than the ones listed above, please choose the *Custom Dataset Terms* option from the *Dataset Terms* drop-down menu.**
**

Not sure which of the above software licenses is most suitable for you?

Please consult:

  - **[Open Source Licenses for Software](https://opensource.org/licenses),**
  - **[Research software citation for researchers](https://cite.research-software.org/researchers/)** &
  - **[why making your software code open is important](https://fair-software.eu/)?**

  - **Ball, A. (2014). ‘[How to License Research Data](https://www.dcc.ac.uk/guidance/how-guides/license-research-data)’. *DCC How-to Guides*. Edinburgh: Digital Curation Centre.**
