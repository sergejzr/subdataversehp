---
title: Enabling dataset review functionality for unpublished datasets
---
Receiving a **General Preview URL** for a dataset allows you to share your dataset (for viewing and downloading of files) before it is published to a wide group of individuals who do not have a user account on DataPublication, for example co-authors of your paper. Anyone you send the Preview URL to will be able to view the dataset in DataPublication without having to log in.

**Anonymous Preview URL

**Receiving a **Anonymous Preview URL** for a dataset allows you to share your dataset anonymously (for viewing and downloading of files) before it is published with a wide group of individuals who do not have a user account on DataPublication, for example reviewers of your article. Anyone you send the Anonymous Preview URL to will be able to view the anonymized\* dataset in DataPublication without having to log in.

\*Metadata that could identify the dataset's author will not be displayed. Non-identifying metadata will be visible.

The dataset's files are not changed and the individuals with the Anonymous Preview URL will be able to access them.

Please note that users of the Anonymous Preview URL will not be able to see the name of the Dataverse that this dataset is in but will be able to see the name of the repository, which might expose the dataset authors' identities.

**Please note:** Please note that the files themselves are not changed and the individuals with the Anonymous Preview URL will be able to access them. **This means that, for double blind review purposes, the information that is usually found in a readme file or similar documentation files (eg. about the authors, funding and other relevant fields that might expose the dataset authors' identities) should be removed before generating the Anonymous Preview URL**. Please only include such information after the external review process of the dataset is complete.

**To verify that all identifying information has been removed or anonymized, it is recommended that you logout and review the dataset as as it would be seen by an Anonymous Preview URL user. **

**Hint:** Note that only one Preview URL (normal or with anonymized access) can be configured per dataset at a time.

If you have any questions let us know <<DP-SUPPORT-MAIL>>

**Hint:** The contributor has the possibility to generate a Preview URL for their unpublished dataset. 

If you are a dataset contributor and would like to generate a Preview URL or Anonymous Preview URL for your unpublished dataset, kindly follow these steps:

1.  Go to the unpublished dataset
2.  Select the “Edit” button
3.  Select “Preview URL” in the dropdown menu
4.  In the pop-up window select “Create General Preview URL” or “Create Anonymous Preview URL”
5.  Copy the Preview URL/Anonymous Preview URL
6.  . The generated link can now be shared with others

To disable a Preview URL and to revoke access, follow the same steps as above until your reach step 3. In the pop-up window click on the “*Disable Preview URL*” or “*Disable Anonymous Preview URL*” button.
