---
title: Choosing a guestbook for your dataset
---
**Hint:** Guestbooks allow you to collect data about who is downloading the files from your datasets. If a guestbook is active in a dataset, any person wanting to download the content will be prompted to fill out the guestbook before receiving the content of the dataset.

If guestbooks are enabled in the collection the dataset is located at, you can select a desired guestbook by going to *Terms* tab, clicking on  *Edit Terms Requirements* and selecting a guestbook.

![guestbook-3](uploads/46cb101aade146e097d855c1aa347bc6/guestbook-3.png){width=1000 height=305}

**Please note:** Please note that currently there are no guestbooks available in DataPublication. If you would like to set up a guestbook for a dataset, please get in touch: <<DP-SUPPORT-MAIL>>

If you are an administrator and would like to create and enable guestbooks for your sub collection, please consult [Guestbooks for sub-collections](/references/Guestbooks-for-sub-collections) in the Administrator Guide.
