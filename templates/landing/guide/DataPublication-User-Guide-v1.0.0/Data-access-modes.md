General information

1.    - DataPublication is a registry for scholar data. [Digital Object Identifiers](https://support.datacite.org/docs/doi-basics) (DOIs) for each dataset in DataPublication are provided by DataCite.
      - DOIs of datasets published in DataPublication may point to the DataPublication landing page
      - The bibliographic and basic metadata of every dataset are freely and openly available on the landing page of DataPublication. Respective licensing permissions of each dataset have to be adhered to.

Access to data stored in the DataPublication platform

  -   - DataPublication enables the publication of research data according to the FAIR principles and the motto „as open as possible and as closed as necessary“ by providing relevant services and licenses.

      - Research data can only be uploaded to DataPublication and published only if they are sufficiently and appropriately anonymized.

        **Please note:** If relevant. please take care that appropriate allowances, like informed consents of study participants are present already at the start of the project.

      - Data can be uploaded directly to DataPublication by the user. The uploaded data receive a DOI upon dataset draft creation, however, the DOI itself becomes active only after the dataset is published. DOIs can be reserved.

      - Data that is generated and stored at your institution's infrastructure and is associated with the generated dataset in DataPublication, can be added to the dataset in question by providing a link to the respective storage infrastructure (for example a [Coscine](https://about.coscine.de/) resource backed by [DataStorage.nrw](https://www.fdm.nrw/technische-fdm-landesdienste)).

      - Any external, published materials that are closely associated with the dataset can be added to the dataset by filling out the "Related Material" Metadata field.

      - The deposited and/or linked data is subject to licensing terms granted by the data depositor. Any user of DataPublication or visitor can access, download and use the data as specified under its licensing information.

      - In certain cases, the data depositor may have restricted the direct (open) access to the data and/or data-specific metadata. For example, the mandatory metadata are findable and accessible to the public, but the data and more specific project-related metadata are not. If this is the case, in order to get access to the data, the data depositor needs to be contacted via the *Contact author* button provided.

      - Published datasets are indexed in external data search engines. Unpublished, draft datasets are not.

      - Upon publication, the dataset’s landing page, bibliographic information, and mandatory metadata entries are visible to the public. If the dataset is not published, the above information is only visible to DataPublication and sub collection administrators, as well as to a limited number of DataPublication users that are defined by the data depositor.

      - For batch inject/download of the data, please contact DataPublication admins:  <<DP-SUPPORT-MAIL>>

**Hint:** If you would like to archive data that should be neither findable nor accessible to others, you can archive it via [Coscine](https://about.coscine.de/) on [DataStorage.nrw](https://www.fdm.nrw/technische-fdm-landesdienste) (10-year archival in line with good scientific practice). Please note that DataPublication does not support the upload, archival or publication of personal data. If you are unsure which platform would be best for your data, we can assist you further.

If you would like to know more about the possibilities of data archival at your institution or in NRW, do contact us, and we will assist you further: <<DP-SUPPORT-MAIL>>
