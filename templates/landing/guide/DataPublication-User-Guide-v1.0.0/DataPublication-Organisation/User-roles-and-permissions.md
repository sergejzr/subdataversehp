---
title: User roles and permissions
---
Users cannot receive a digital object identifier ([DOI)](https://support.datacite.org/docs/doi-basics) for their data or publish the dataset in DataPublication (or in a designated sub-collection) standalone.

All entries have to be submitted for review and are curated by the DataPublication curation team (technical and content integrity check). **[DP-TODO-05]**

In the case of sub-collections, the respective sub-collection administrator is responsible for curating the content.

**Hint:** For a general overview of roles available in the Dataverse software, please go to: <https://guides.dataverse.org/en/latest/user/dataverse-management.html#setting-access-configurations>
